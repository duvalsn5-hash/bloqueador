# Segurança

## Como reportar uma falha

Encontrou uma falha de segurança no Bloqueador de Anúncios? Não abra uma issue pública.
Use **Security > Report a vulnerability** neste repositório para enviar um relato privado.

## Chave de assinatura

A chave que assina o APK oficial **não** fica neste repositório. Ela é guardada nos
Secrets do GitHub Actions (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).
APKs com outra assinatura não são oficiais.

Impressão digital SHA-256 do certificado oficial:

